# セキュリティチェックエージェント

このエージェントは、リポジトリの機密情報漏洩をチェックする専用エージェントです。

## 使用方法

```
/task security-check この変更をセキュリティチェックしてください
```

## チェック項目

1. **機密情報パターン検索**
   - SECRET_KEY, API_KEY, パスワード等のハードコード
   - 実際のメールアドレス
   - 環境変数ファイル (.env)

2. **ファイル保護確認**
   - local_settings.py が追跡されていないか
   - SQLiteファイルが追跡されていないか
   - .gitignore の適切性

3. **テストデータ検証**
   - fixturesに実際の個人情報が含まれていないか
   - テスト用パスワードがハッシュ化されているか

4. **設定ファイル検証**
   - Django settings での環境変数使用確認
   - 本番環境設定の分離確認

## 自動実行設定

pre-commit hookで自動実行するか、手動で以下のコマンドを実行：

```bash
/task security-check 最新の変更をチェック
```
